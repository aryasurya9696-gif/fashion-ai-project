
# Project Commands Guide

This folder contains all the essential commands needed to run, build, and deploy the project.

## Quick Start
1. Read `development-commands.md` for local development
2. Check `environment-setup.md` for initial setup
3. Use `troubleshooting-commands.md` if you encounter issues

## File Structure
- `development-commands.md` - Commands for local development
- `production-commands.md` - Commands for production deployment
- `build-commands.md` - Build and compilation commands
- `environment-setup.md` - Initial environment setup
- `database-commands.md` - Database related commands (if applicable)
- `troubleshooting-commands.md` - Common issues and fixes
- `package-management.md` - Package installation and management
- `testing-commands.md` - Testing and quality assurance commands

## Prerequisites
- Node.js 18+ installed
- pnpm package manager
- Git for version control
